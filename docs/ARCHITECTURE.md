> 版本：v0.4.0
> 日期：2026-07-31

## 架构

```
                    ┌──────────────────────────────┐
                    │  美股 AI/半导体局部观察池      │
                    │  SOXX / NVDA / ASML / ...     │
                    │  (AKShare stock_us_hist)      │
                    └──────────┬───────────────────┘
                               │ 并行接入，辅助最终判断
                               ▼
┌──────────────────────────────────────────────────────────┐
│ ① A股全市场 ETF 轮动（etf_signal）                        │
│   Discover：全量 ETF → 横截面 RPS15/20/60 → 发现主线      │
│   产出：rotation_{date}.parquet / etf_rotation_{date}.html│
└────────────────────────┬─────────────────────────────────┘
                         │ 指向强势板块
                         ▼
┌──────────────────────────────────────────────────────────┐
│ ② 申万二级行业确认（sw_industry_rps confirm）             │
│   Confirm：10 重点行业 → 群共振/子主题/龙头广度/背离       │
│   产出：confirmation_{date}.parquet                       │
└────────────────────────┬─────────────────────────────────┘
                         │ 验证趋势质量
                         ▼
┌──────────────────────────────────────────────────────────┐
│ ③ 交易标的筛选（selection）                               │
│   Select：表达方式决策（ETF vs 个股）→ 执行对象压缩        │
│   调用 Trend Engine 计算个股趋势                           │
└────────────────────────┬─────────────────────────────────┘
                         │
                         ▼
              ┌──────────────────────────────┐
              │  Candidate JSON（候选资产对象） │
              │  tradable_candidates_{date}   │
              └──────────────┬───────────────┘
                             │
                             ▼
              ┌──────────────────────────────┐
              │  ④ Portfolio（执行，未来）     │
              │  买多少 / 何时买 / 何时卖       │
              └──────────────────────────────┘

   Trend Engine（trend_engine，Selection 的依赖，非主链）
        ┌──────────────────────────────┐
        │  行情获取 / 缓存 / 多源回退    │
        │  技术指标 / 0-100 趋势评分     │
        │  ↑ 仅被 Selection 调用，无独立入口 │
        └──────────────────────────────┘
```

**信号主链**：Layer ① ETF 发现 → Layer ② 行业确认 → Layer ③ 交易候选（Candidate JSON）→ Layer ④ 执行

**Trend Engine**：不是主链一环，而是 Selection 内部调用的依赖（原 stock_trend 底层能力重组），不暴露独立业务入口。

**并行接入**：美股 AI/半导体局部观察池，不参与主链驱动，只辅助最终判断

## 三层纵向递进

### ① A股全市场 ETF 轮动

**核心问题**：AI、科技、半导体在全部 A 股 ETF 资产中处于什么位置？

**职责**：从全量 ETF 中发现当前主线，不预设 AI 一定是主线。

**重点观察**：

| 维度 | 指标 |
|------|------|
| 横截面强度 | RPS15 / RPS20 / RPS60 |
| 收益排名 | 5日 / 10日 / 20日收益在全部 ETF 中的排名 |
| 趋势状态 | BUY_CANDIDATE / STRONG_WATCH / WATCH 分布 |
| 排名变化 | 板块 RPS15 中位数过去 5 日排名变动 |
| 强势数量 | 进入 RPS15 Top 10% / Top 20% 的 ETF 数量 |
| 内部扩散 | 板块内部 RPS 离散度，强势标的占比变化 |

**示例判断**：

```
全市场 ETF 数量：300
AI/科技/半导体 ETF：28

进入 RPS15 Top 10%：9
进入 RPS15 Top 20%：17
板块 RPS15 中位数：87
过去 5 日排名提升：+21 位
```

**这一层决定**：AI/科技/半导体是否正在成为 A 股主线。

### ② 申万二级行业确认

**核心问题**：ETF 的强势是否得到了底层行业的支持？

**职责**：当 ETF 信号指向科技方向时，从中观行业层面验证趋势质量。

**重点关注行业**：

| 行业 | 关联性 |
|------|--------|
| 半导体 | 核心 |
| 元件 | 核心 |
| 消费电子 | 核心 |
| 通信设备 | 相关 |
| 通信服务 | 相关 |
| 软件开发 | 相关 |
| IT 服务 | 相关 |
| 计算机设备 | 相关 |
| 自动化设备 | 相关 |
| 光学光电子 | 相关 |

**识别维度**：

| 维度 | 判断 |
|------|------|
| 单一 vs 群共振 | 单个行业强势，还是行业群同步走强 |
| 龙头 vs 广泛上涨 | 少数龙头贡献（高 HHI），还是广泛参与（高参与率） |
| ETF vs 行业背离 | ETF 强但行业弱 → 可能为资金交易行为，非趋势确认 |

**直接复用的现有能力**：

- Top 3 贡献占比
- HHI（贡献集中度）
- 上涨参与率
- 双覆盖率（ETF × 行业）
- 4×4 驱动分类

**这一层决定**：ETF 层面的强势是真实行业趋势还是短期交易行为。

### ③ 交易标的筛选与表达方式选择（selection）

**核心问题**：这个已确认方向，应当由哪只 ETF、哪类股票来交易？

**职责**：执行对象压缩层。把 Layer①/② 的结论压缩成「用 ETF 还是个股、用宽主题还是细分主题、选哪一只」，不回答买多少/何时买卖（Layer 4）。

**标的分层**（按优先级）：

| 类型 | 示例 |
|------|------|
| 主题 ETF | AI 人工智能 ETF、半导体 ETF、通信 ETF |
| 细分行业 ETF | 芯片 ETF、软件 ETF、计算机 ETF |
| 行业龙头 | 中际旭创、科大讯飞、寒武纪 |
| 高弹性标的 | 小鹏、蔚来、地平线 |
| 设备与上游 | 韦尔股份、德赛西威 |

**表达方式决策**（基于 Layer② 上涨结构）：
- 广泛上涨（参与率高 + HHI 低）→ 优先 ETF
- 龙头主导（HHI/Top3 高）→ 优先龙头个股，ETF 作低风险替代
- 扩散形成 → ETF 核心 + 龙头卫星
- 行业未确认 → 仅 WATCHLIST

**输出**：结构化候选资产对象（JSON）为唯一事实源，HTML 仅为可视化。每子主题压缩为：1 核心 ETF + 1–2 细分 ETF + 2–3 龙头 + 高弹性/上游观察。

**Trend Engine（内部依赖）**：原 stock_trend 底层能力（行情获取/缓存/多源/指标/0–100 评分）重组为 `trend_engine`，仅被 selection 调用，不暴露独立业务入口。

**Layer 4 边界**：本层只回答「买什么」。仓位/入场/止损/加仓/减仓/组合相关性属于未来 Layer 4 Portfolio（Execution）。

## 并行辅助：美股 AI/半导体局部观察池

**不参与主链驱动，只辅助最终判断**

三个固定 Basket：

| Basket | 标的 |
|--------|------|
| 半导体市场 | SOXX / SMH / SOXL / SOXS |
| AI 芯片 | NVDA / AMD / AVGO / TSM / ARM / MU |
| 半导体设备 | ASML / AMAT / LRCX / KLAC |

**数据源**：AKShare `stock_us_hist` / `stock_us_daily`

**原则**：
- 否决权，非驱动力
- 国内无信号时不因美股强而买入
- 国内信号强 + 美股弱 → 保持观察，不追高
- 国内信号强 + 美股强或无冲突 → 提高置信度

## 输出

| 状态 | 含义 |
|------|------|
| 买入 | 三层共振（ETF 强 + 行业确认 + 标的技术有效） |
| 持有 | 趋势仍有效，不触发退出条件 |
| 卖出 | 趋势失效、行业确认转弱或风险触发 |

## 与四层决策框架的关系

```
长期投资方向（配置层）
    AI / 科技 / 半导体（当前）

        │ 决定系统关注什么

第一层：市场状态（Discovery）
    全市场 ETF 轮动，判断关注方向是否成为市场主线

第二层：行业确认（Confirmation）
    验证关注方向是否得到行业共振支持

第三层：交易候选（Selection）
    将确认后的方向压缩为可交易资产（ETF / 龙头 / 高弹性）

第四层：Portfolio（Execution）
    仓位、买卖时点、风险控制
```

**配置层不参与每日计算**：Investment Focus 是人工设定的长期研究方向，决定整个系统关注什么。Layer ①/②/③ 始终围绕这个方向，分别回答三个问题——**它是不是主线？是否得到确认？应该如何表达？**
