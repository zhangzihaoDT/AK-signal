**可确认的边界**：两者是不同体系下的指数标识，现有证据不支持把 881062 当成 801043 的转码或价格代理。尚未完整取得两者的基日、除数修正规则、样本调整及权重公式，因此不臆测具体加权差异，也不声称成分股必然不同。
