## 简报正文

对冻结后的 `REPAIR_RETEST_V1` 做了历史回测，区间为 **2022-01-01 → 2026-08-31**，
覆盖 **1127 个交易日、1596 只 raw ETF**。本次只验证规则触发频率和后续赔率，不调参、不修改 TARGET 定义。

主要发现：

* **TARGET 并不稀疏**：20.8% 的交易日至少出现 1 个 TARGET，共 866 个 episodes、368 只 ETF，
  单 ETF 最大贡献仅 1.2%。因此，当前出现 `0 TARGET` 更可能是真实市场状态，而不是规则过严。
* **但存在明显空窗期**：历史最长连续 **132 个交易日无 TARGET**，说明该信号具有较强的阶段性。
* **TARGET 后绝对表现较好**：120D 中位收益 **+8.32%**，胜率 **79%**；明显好于 NEAR_MISS 和域内非 TARGET。
* **但独立 Alpha 较弱**：120D 市场相对超额仅 **+0.11pp**，相对域内非 TARGET 增量约 **+1.73pp**，未达到 +3pp 门槛。
* **时间依赖明显**：2022 和 2024 合计贡献约 **84%** 的 TARGET events，2025–2026 明显减少。

结论：

**REPAIR_RETEST_V1 已通过“可触发性验证”，但尚未通过“独立 Alpha 验证”。TARGET 更适合定义为“结构触发候选”，
即底部资产已出现值得进入下一层判断的 Repair-Retest 结构，而不是直接买入信号。**

---

## 结论定位（与 AGENTS 口径一致）

一句话：**Signal Incidence ✅ 通过；Independent Alpha ❌ 未通过 → 定位为筛选候选，不是交易信号。**

- 规则会稳定地告诉你「谁底部出现了值得看的修复结构」（结构触发候选）。
- 但「出现 TARGET 就该买、就能跑赢大盘」的证据不支持。
- 据此，TARGET 进入**下一层判断**（Current Odds / 跨年证据 / 综合判断），而不是直接下买入指令。

## 口径说明

- `reliable_360 = full_360_sample ∧ ¬unreliable_360 ∧ ¬flat_price_noise`；
  `long_term_bottom = pos120≤20 ∧ pos360≤20`；`in_domain = reliable ∧ long_term_bottom`。
- **TARGET = 域内 + pos60 Q1(<14.55) × pos120 Q3(>15.82)**，只读冻结 cut，绝不重算（`_verify_frozen` 漂移守卫）。
- 事件口径：同一 ETF 连续同 stage → 一个 episode（entry=首次进入日）；隔 ≥1 交易日再入 → 新 episode。
- 前向收益在事件起始日计算，右截断样本显式标记、不进入主统计；全部 as-of，无 look-ahead。
- 基准 = 同市场横截面中位前向收益（延续 V1 outcome 定义 `excess_vs_etf_market`）。
