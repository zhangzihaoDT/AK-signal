# 日报 04 趋势启动早期识别 V1

2026-10-24 · `stock_group_trend_start_v1` · 日报布局 `daily_observation_modules_v8`。

原地替换 `stock_group_activity_v1` 的最终判断。目的为尽早发现值得研究的启动迹象，容许误报；不输出综合评分、交易建议、目标价或仓位动作。**全部阈值仍为候选参数，未验证。** 合成测试通过不等于历史预测能力成立。

## 输入与结构指数

- 8 个研究篮子 + 高现金流参照；直接复用 `comparison_baskets()` / `constituents()`，保留 `group` 和 `weighting`。不另抄股票清单；跨组允许重复，组内重复注册报错，政策排除禾赛。
- 只读取本批 `stock_update_audit_<date>.json` 指向的不可变快照。检查清单 SHA256、批次日期/来源/当前资产配置签名、快照内容摘要、股票身份、股票趋势的日期及 snapshot_id。沪深300也从同一清单读取，必须是长桥 `000300.SH`、index/index_level。
- 原始 OHLC 仍严格验证。各市场日历覆盖内的原生交易日缺口严格拒绝，包括 A 股休市时的港股缺口；不先求交集再丢掉缺失。历史不足或任何成分/基准无效 → UNAVAILABLE。数据异常不能变成 NO_SETUP。
- 在所有成分与基准有可靠价格后的**首个真实自然季度末**收盘设结构指数为100；该日必须全部成分开市。复用 `align_assets()` / `nav_from_panel(..., quarterly)` 的组间等权、组内等权及自然季末重置。由于该日原本就是 Compare 目标权重重置日，其后归一化路径一致；绝不以中位数代替结构收益。
- 只计算该锚点以后的结构历史。比锚点更早的行情用于原生单日收益基线，不伪造结构历史。所有成分在锚点已有价格，不会将任意短历史冒充上市前现金。历史基座随供应商滚动截短时锚点可能右移，必须重新验收并保留 input_hash/anchor；不能将不同快照的历史结果当作不变历史。
- 结构净值按 HS300 交易日历估值。Compare 算法在**已验证休市**时持有上次估值；这是估值约定，不是新增的零收益观察。停牌/缺失的原生交易日报价不允许这样处理。
- 单日异动保留每只股票自己的原生一交易日收益，再取共同开市日交集，前60个共同开市日为基线，不含当日。分组当前日有市场休市 → UNAVAILABLE。
- 历史判定要求每个成分的5/10/20日参与度端点均有实际价格，及10日参与度的5日前对照完整。Compare 的有效端点分母定义不变，但日报要求 valid_count=全组人数；端点休市时冻结状态、跳过观察，不补零、不缩小分母冒充完整组。
- 保留 `price_basis_verified=false`、history_limitation、快照及日历摘要、配置摘要、实际指标、条件布尔值、原始异常证据及完整历史状态。生成时间在日报批次摘要审计；事实文件记录 `input_fetched_at`，同输入可逐字节重复生成。

## 指标定义

令 N 为 QR 结构净值，B 为同源沪深300净值，RS 为二者归一化比值（Compare `relative_strength`）。MA5/10/20 是最近5/10/20个 HS300 交易日 N 的简单均值。

- **RS20Δ** = `100 × (RS_t / RS_(t−20) − 1)`，字段 `rs_20d_pct`；与 Compare 完全相同。现有 Compare 并没有另一套独立的“RS20”数值，不另造同名指标。滚动20日相对收益和它的改善分别记录。
- **RS20Δ较5日前变化** = `rs_20d_pct_t − rs_20d_pct_(t−5)`，字段 `rs_20d_change_5d_pp`，单位pp；不是 RS20Δ 自身的定义。
- **持续改善**：最近5个 HS300 交易日中，RS20Δ至少3日较前日增加；同时 RS_t / RS_(t−5) − 1 > 0。
- **5/10/20日参与度**：两个端点均有价格且区间收益>0的股票数 / 有效股票数；复用 Compare `_participation`，平盘不算上涨，不使用结构权重。
- **价格止跌转向**：N>MA5，5日收益>0，MA5较3日前上升。
- **价格转强结构**：N>MA20，MA5>MA20，MA20较3日前不下降，5日收益>0。
- **已有价格上行背景**：此前连续5次有效观察 N>MA20、MA20较3日前上升、20日收益≥3%。独立于相对强度，避免上涨但跑输基准的老趋势被包装成新启动。

## 候选触发规则

所有首次启动均先进入 WATCH。两条路径均要求尚无活跃事件、此前至少5次有效 NO_SETUP 重置观察，且不是已有价格上行背景。没有“任意两项满足”的计分。

### A 突发式

同时满足：

1. 下列正向单日线索至少一种：GROUP_UP、BREADTH_UP、正向 MEMBER_MOVE。
2. 结构指数当日上涨，成分原生单日收益中位数>0，上涨股票占比≥50%。
3. 背景与重置门控通过。下跌中的集体反弹可以进入 WATCH，不可一步确认。

保留的单日线索基础参数（**仅为未验证候选值**）：

| 线索 | 条件（今日不进入历史基线） |
| --- | --- |
| GROUP_UP | ≥3只；中位数≥2%，相对前60日均值的正偏离≥max(2.5×样本标准差,2pp)，上涨占比≥60% |
| BREADTH_UP | ≥3只；上涨数增加≥2只且占比增幅≥30pp，该变化相对历史变化均值的偏离≥max(2×标准差,30pp) |
| 正向 MEMBER_MOVE | 个股日涨幅≥5%，相对自身前60日均值的绝对偏离≥max(3×标准差,5pp) |

向下异动也保留作审计，但不是启动触发。单股暴涨、其他成分不动，不能通过集体上涨门控。参数继承旧版的描述性候选值，没有把旧版仅按提示频率的检查当作启动有效性认证。

### B 渐进式

同时满足：

1. 价格止跌转向成立，不要求突破MA20。
2. RS最近5日上升，RS20Δ最近5日中至少3日改善，累计较5日前改善≥0.5pp。
3. 5日参与度≥50%，10日参与度较5日前扩大≥10pp。
4. 背景与重置门控通过。不依赖极端单日涨幅。

## 状态机

全历史从结构锚点逐日重放，不读取历史状态文件；仅使用截至当日的指标。预热、缺失与闭市端点显示 UNAVAILABLE 并冻结计数，不当作失败或零收益。之前状态指上一**有效观察日**，不是上一日历日。

| 状态/转换 | 完整条件 |
| --- | --- |
| NO_SETUP → WATCH | 满足上述任一路径；`first_trigger=true`，保存事件起始日和收盘结构净值 |
| WATCH → EMERGING | 连续2次有效观察具备价格转强结构，且10日参与度≥60%，且（RS20Δ>0 **或** 较5日前改善≥0.5pp）；第一次触发日只给WATCH |
| EMERGING → CONFIRMED | 连续10次有效观察满足上述支持条件，另有20日收益≥3%、20日参与度≥60%、RS20Δ≥0 |
| EMERGING/CONFIRMED → WATCH | 连续2次失去价格转强结构；保留原事件ID，不标新机会；WATCH等待计时从降级重新开始 |
| 活跃状态 → NO_SETUP（失效） | N较首次WATCH收盘下跌≥3%，或连续2次 N<MA10 且5日收益<0；失效优先于升级 |
| WATCH → NO_SETUP（过期） | WATCH连续等待10次有效观察，仍没有价格转强与支持；含降级后重新计时 |
| 重新触发 | 从失效/过期当次开始，在NO_SETUP且没有已有价格上行条件时累积5次重置观察；重新出现A/B才开新事件 |
| 左边界/无事件的老趋势 | 已有价格上行背景且满足连续2次支持时记为TRACKING/EMERGING；具备10次持续证据才为CONFIRMED；首次触发永远为false |
| UNAVAILABLE | 输入、日历、足够历史或完整参与度端点条件不满足；不能解释为无机会 |

先验计数不凭空假设：历史左边界处需要积累有效观察。冷却/重置可能漏掉快速二次反弹，3%失效阈值可能对高波动组过敏，均作为后续前瞻验证项，不据当前样本调优。

## 历史评估定义与复算

独立价格事件：20个HS300交易日累计上涨≥8%，最后5日收盘均高于20日前收盘至少4%，相邻确认至少间隔20日。事件不使用MA、RS、参与度或候选状态。它定义非重叠的上涨扩张窗口，持续长趋势也可能贡献多个事件，不能声称枚举了所有真实趋势。

- 起点为该20日窗口内最低收盘日。捕获要求新WATCH发生在确认前20日内、且不早于起点前5日；确认同日不算提前发现。
- 捕获率分母只纳入确认前20日已越过预热起点的事件。提前量按HS300交易日计算。
- 假启动：WATCH之后20日没有独立价格确认；末尾未满20日单独列为未成熟，不算失败。
- 5/10/20日收益使用当日收盘到未来对应收盘；各期限列有效样本数。最大不利波动为未来20日最低收盘相对触发收盘（上限0），不含盘中波动。
- 频率为首次WATCH数/有效观察数，每百日展示。完整漏报上下文、逐事件及逐提示结果保存JSON；重叠篮子和前瞻窗口不能当作独立样本。
- 开发期探索性复算，最终候选未以独立留出样本验证；不按前瞻收益优化参数。不具备历史成分版本或当时复权快照，故只是**当前名单/当前快照历史复算**，不得当作历史可执行回测或独立样本外认证。
