## 等预算对照（2026-10-24 补充复核）

捕获率随提示数量单调上升，并在100%饱和，因此提示数不同的两版不能只比捕获率。下表把两版压到相同提示预算：按各版提示总数把预算等比分配到9组，每组随机抽取该数量的首次WATCH，重复2000次取期望；改用全局分配（由版本自行决定预算落在哪组）重复1000次，结论相同。捕获窗口与`check_group_activity`一致（`max(确认日-20, 起点-5) ≤ i < 确认日`），脚本重算两版共154个(事件,版本)判定，与`comparison.json`逐条一致。

| ---: | ---: | ---: |

| 60 | 24.8 | 22.5 |

| 100 | 39.6 | 35.3 |

两版曲线在40至113的每个预算上不相交，V1始终在上方。V1在113为其全量，捕获44与上表一致，可作为交叉校验。即：V2的捕获提升来自提示数量增加，等预算下判别力不优于V1；V2需要支出约两倍提示预算才取得更高覆盖。88.31%应读作“在该预算下不漏更多”，不能读作“预测能力更强”。

该对照回答“同样留意次数下谁覆盖更多”，不等价于“V2提高阈值后的表现”：两版都没有可用于截断的内部评分，随机抽取是在缺少评分时的唯一中性做法。抽取只使用提示日期，不使用事件或未来收益。
