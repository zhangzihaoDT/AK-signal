# 通达信研究行业日线包：最小批量验收

验收日期：2026-10-16。初始验收结论：**128 行业文件、解析与历史收益率对照通过；每日更新稳定性待实测。** 后续用户决策已授权直接正式集成，不以连续五日稳定性观察作为切换前置；当前正式运行仍执行严格目标日与完整性门控，稳定性记录继续积累。详见[正式集成决策](../../config/decisions/20261016_market_data_architecture.md)及[集成说明](../TDX_INDUSTRY_INTEGRATION.md)。

## 验收对象与口径

固定使用 `tdx_research_industry_universe_20261016.csv` 中 `taxonomy_key` 长度为 5 的 **128 个二级研究行业**，并非 345 个混合层级叶子节点。网站代码和行业名称 128/128 一致。未强制与申万分类映射。

数据源为通达信官方板块指数日线；参考网站为用户指定的 [RPS 监控](https://rps.shgso.top/)。网站标示未复权。`<IIIIIfII` 每记录 32 字节，OHLC 整数除以 100，尾部保留字段不作为价格。收益率按同一文件内前 N 根交易日收盘价 `close[t]/close[t-N]-1` 计算，不补价格、不跨来源拼接。

网站共同日期为 **2026-09-21、22、23、24、28**，窗口为 **1/5/10/15** 个交易日。预设收益率绝对容差为 `1e-6`（小数收益率，即 0.0001 个百分点）；实测最大误差 `2.220446049250313e-16`。参考网站截至本次抓取仅到 **2026-09-28**，所以不能用它证明 10 月 15 日价格一致。这里验证收益率，不把网站 RPS 值当作 AKsignal 计算规范。

电子化学品 `881479` 只有 **73 根**，起始日 2026-06-29。其 1/5/10/15 日收益对照通过，但不得生成 120/250 日收益率或趋势指标；不足窗口必须缺失并记录有效横截面数量，不能把缺失填成 0，也不能声称所有窗口都有 128 个有效样本。本次没有完成全部历史交易日历缺口验收。

## 官方更新证据及边界

[个人完整日线包页面](https://www.tdx.com.cn/article/vipdata.html) 指向 `https://data.tdx.com.cn/vipdoc/hsjday.zip`，官方更新信息显示 **2026-10-15 15:58:54 CST**；HTTP Last-Modified 与该时间一致，ETag 为 `"6ad087be-20edcf56"`。通过 HTTP Range 读取 ZIP 中央目录，共 12,463 项，选取本次 128 个行业记录留证。

[官方数据维护页面](https://www.tdx.com.cn/article/alldata.html) 提供独立板块指数包 `https://www.tdx.com.cn/products/data/data/vipdoc/tdxzs_day.zip`；本次 HTTP 大小 **79,279,436 字节**，Last-Modified **2026-10-15 16:03:44 CST**，ETag `"6ad088e0-4b9b54c"`。本地同名包 SHA256 为 `ab5d9565c2da9fc3b6d7a997948d8c9d2b2da53c93fa0ac6d71e4b62f48f4cd2`；对应行业文件与官方全市场目录 CRC 相同。没有把 CRC 相同描述为本地整包与远程整包 SHA256 相同。

[官方分日下载目录](https://www.tdx.com.cn/tdxonline/down/datadown_dc.html) 最近五个交易日 **10/09、10/12、10/13、10/14、10/15** 的 G3 日线更新包全部 HTTP 200、ZIP CRC 完整，每份 COD 都能找到 128 个代码字符串，Last-Modified 均为当日 **17:00:03–17:00:05 CST**。这是回溯可下载性证据，不是当时实时观测的发布时间承诺。此类包是 MDT/COD 格式，本次未解码 MDT 价格，代码字符串出现也不代表对应行情已经验真；不能代替上述独立 `.day` ZIP 每日更新验收。

## 初始切换建议与后续决策

目标链路技术方向可确定为：

`通达信官方日线数据包 → 本地行业价格库 → 自算 RPS → Daily Report`

本次验收当时提出连续 **5 个交易日**采样作为建议；该建议随后被用户明确决定不作为正式集成前置条件。正式集成已启用，运行仍保存获取时间、HTTP 标识、文件摘要与目标日覆盖证据；更新失败、目标日缺失或横截面不完整时标记 unavailable，不更新为有效行业事实。稳定性记录继续积累，但不是当前切换门槛。

独立 RPS 验证还需固定横截面、窗口、并列排名与缺失处理；网站收益率对照通过不能代替这项计算验收。正式发布须携带 `TDX Research Industry`、固定版本、实际来源、价格口径、trade_date 和各窗口有效样本数。
