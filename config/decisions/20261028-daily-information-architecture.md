# 日报信息架构重整（v0.7.3）

用户要求：把日报从“指标堆叠”改为三层阅读，固定各模块默认字段，明确详情与审计边界。只改 Report 的渲染与信息架构，不改行情管道、指标计算和研究信号规则。

- 阅读顺序：市场整体（01 市场环境）→ 行业结构（02）→ ETF 产品（03）→ 研究主线（04）→ 数据可信度（05）。Summary 层由已验收事实按固定模板生成并标注为“展示摘要”。
- 核心指数默认 6 列（指数、当日、5/20/60日涨跌、均线状态），收盘点位/来源/实际行情日/数据状态进入详情；IC 只保留合约、基差率、持仓量，全部到期合约保留以便比较期限结构。
- 行业默认展示前 15 个（RPS15/RPS5/阶段），当日涨幅与当日 RPS 进入详情；新增“行业变化观察”，从两份已验收快照派生首次进入前20、首次转入已形成趋势、趋势退潮。没有可对照的已登记快照即“无法判定”，不补造。
- ETF 分类概览移回 ETF 模块，并标注已分类/未分类样本数；趋势活跃不再重复 MA20/MA60 数值；位置默认采用 120日位置，但底部标签**仍沿用原 120/360 日低位规则**，不因展示列调整改写定义；同主题产品标为“名称推断分组”，逐产品计算不合并。
- “个股观察”更名为“研究主线”，一张表：主线、趋势阶段、启动状态、观察变化、线索；RS/参与度/规则 trace 与成员表进入详情。“已有机会/新增机会”展示层改为“已有观察线索/新增观察线索”。当前结构与相对上一观察日的变化分列陈述。
- 数据质量改为异常驱动：覆盖率四项 + 需关注限制；正常来源与口径进入技术详情，逐日不再重复。
- 已知限制：ETF 位置表按“底部变化 → 长期低位 → 120日位置”排序，默认 20 行中“进入底部/离开底部”未必全部可见，其余在展开区。后续如需“位置变化事件优先”另立条款，本版不隐式改变排序。
- 保留：五段锚点、`stock-group-*` 锚点、模块级降级与 PARTIAL 规则、`UNVALIDATED` 与 `price_basis_verified=false`。

补丁（同日）：分类口径在展示层统一（空白/NaN/unclassified 均为未分类）；排序键按数值与文本规范化；覆盖率读取与 JSON 同一份模块回执；摘要去除重复读数；分类概览剔除“其他”兜底行（合计与已分类样本一致）；行业变化登记改为公布目录规范名，修复“永远无法对照”的缺陷。指标定义与信号规则未变。

工程契约与验收见 `docs/DAILY_INFORMATION_ARCHITECTURE.md`。
